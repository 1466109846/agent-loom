## 结构修订 6 复测

2026-11-24，同一台机器。对象是 `c128cec` 之上的改动：修订号升为 6，新增 Go、Java、C/C++ 和 Vue 单文件组件；原有语言只有 ECMAScript 的两处调整，Rust 和 Python 的规则不变。

- **按名字找文件。** Go 和 Java 的引用不写路径。文件登记自己提供的声明键（Go 是导入路径加包名，Java 是包名），引用方给出“某个键里的某个顶层名字”，索引到声明处去对。Go 的导入路径靠各级 `go.mod` 的模块路径对上目录；`go.mod` 由索引读出后交给解析器，它变了，全部 Go 文件重算。
- **同根才算确定。** 按名字找到的目标要同时满足四条才报“静态确定”：写法在语法上确定（Go 的 `包名.导出名`、同包的包级名字和落到单文件包上的导入，Java 的单类型导入和静态导入），只对上一处声明，命中的不是回退候选，使用方与目标同属一个根。Go 的根是模块，文件名带系统或架构后缀、写了 `//go:build` 或用了 cgo 的文件不属于任何根；Java 的根是目录去掉包路径后剩下的源码根。Java 的同包类型和按需导入带来的类型、Go 点导入带来的名字，一律只报“可能”。
- **只提到名字的不算缺口。** 一个名字在项目里对不上任何声明时，多半来自标准库或第三方，记为与项目无关，不计入待定，也不列在查询结果的未确定项里。
- **包含指令。** C 和 C++ 只读 `#include`，按预处理的词法规则扫描，不建语法树，不展开宏，不求值条件。引号形式先找使用方旁边的文件，命中且不在条件编译里算“静态确定”，头文件保护不算条件。没有命中时，把项目里路径以所写内容结尾的头文件当候选，只报“可能”：包含路径写在编译参数里，Loom 读不到。只有文件名的尖括号包含不猜。
- **Vue 单文件组件。** 只读根级的 `<script>` 和 `<script setup>`，按 `lang` 用 JS、TS 或 TSX 的规则解析，行号换算成整份文件的行号。模板不解析。
- **ECMAScript 的两处调整。** 省略扩展名的相对导入在八种脚本扩展名和 `index.*` 都落空时，再试同名的 `.vue` 和 `index.vue`，TypeScript 使用方另试 `.d.ts`，命中只报“可能”。JavaScript 语法读不通的文件改用 TSX 语法再读一次，后者读得通就用它：tree-sitter-javascript 0.25.0 不接受 `class`、`for` 这类保留字作 JSX 属性名。写了类型标注的 `.js` 文件因此也会被读通。
