# 库放在哪、怎么搬

读者是编码助手。搬库和改默认位置，都要用户先说了目标位置才做。

## 看现在在哪

`loom stats` 的第二行是 `库：<路径> · <大小>`。没有特别设置时，库在项目的 `.loom` 目录里。

## 把这个项目的库搬到别处

1. 目标目录由用户给出。
2. 预演，不改任何东西：

   ```
   loom db move <目标目录>
   ```

   它输出当前位置、大小和目标位置。目标是目录时，库放在 `<目标目录>/<项目标识>/loom.db`。把目标位置给用户确认。
3. 执行：

   ```
   loom db move <目标目录> --yes
   ```

4. 核对：`loom stats` 的位置是新位置，记忆条数没变；再调一次会话工具 `resume`。

- 报“还有会话在使用这个库”：别的窗口里有调用正在进行。等几秒重试；仍然不行，请用户结束其他正在使用这个项目的会话。不要去结束进程。
- 中途失败时原库不动，可以重试。

## 以后新接入的项目都放到某个目录

```
loom config set storage.data_dir <目录的绝对路径>
```

只影响之后新绑定的项目，库建在 `<目录>/<项目标识>/loom.db`。已有的项目要分别 `loom db move`。取消：`loom config unset storage.data_dir`。

## 库文件被手工挪动过

命令会报库不在原来的位置，并给出重新关联的写法：

```
loom --root <项目根> init --db <库文件的新位置>
```

## 不要做的事

- 不要直接复制、移动或删除库文件和它旁边的 `-wal`、`-shm` 文件；搬库用 `loom db move`。
- 不要把库放到网络共享盘或云同步目录（网盘、OneDrive 一类）。SQLite 在这些位置上可能损坏。
